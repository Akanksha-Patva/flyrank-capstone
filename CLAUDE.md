# FlyRank AI Capstone Instructions

## Project Overview

This repository contains my FlyRank AI Frontend Engineering Capstone project.

## Tech Stack

- React
- Next.js
- TypeScript
- Tailwind CSS
- Node.js

## Coding Standards

- Use TypeScript whenever possible.
- Use functional React components.
- Keep components modular and reusable.
- Write clean and readable code.
- Use meaningful variable and function names.
- Avoid unnecessary comments.

## Git

Follow Conventional Commits.

Examples:

feat: add login page

fix: resolve navbar bug

docs: update README

style: format files

refactor: simplify component

## AI Assistant Guidelines

Before generating code:

- Explain your approach briefly.
- Suggest best practices.
- Avoid unnecessary dependencies.
- Keep the code production-ready.

## Project Goal

Build a modern AI-powered frontend following professional engineering practices.
